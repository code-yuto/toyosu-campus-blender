### PLATEAUデータについて
- `bldg/lod2/53393693_...` … テクスチャ付きの詳しい建物モデル（キャンパスがあるメッシュ）
- `bldg/lod1/...` … 箱形の簡単な建物モデル（53393694 はキャンパスの東隣）
- `dem/` … 地形、`brid/` … 橋
- 座標系：平面直角座標系 第IX系（EPSG:6677）、単位はメートル。原点から遠く離れた位置に読み込まれるので、Blenderで読み込んだら原点の近くに移動させる
- **2020年版のデータなので、2022年完成の本部棟は入っていない可能性が高い** → 本部棟は写真とフロアマップを見て自分で作る
- 出典：国土交通省 Project PLATEAU（G空間情報センター、https://www.geospatial.jp/ckan/dataset/plateau-tokyo23ku ）

- 教室のドア、窓、階段、トイレ入口など、何度も出てくるパーツ
- 歩いて測った廊下の長さ（1歩 ≒ 0.7m）
- Google マップの航空写真・3D表示のスクリーンショット、ストリートビュー
